# AsfaltoClub / Moteros 🏍️

[![Flutter](https://img.shields.io/badge/Flutter-3.12+-blue?logo=flutter)](https://flutter.dev)
[![Supabase](https://img.shields.io/badge/Supabase-backend-green?logo=supabase)](https://supabase.com)
[![v0.5.2](https://img.shields.io/badge/version-0.5.2--alpha-orange)](https://github.com/eabarriosTGC/Moteros/releases)

**AsfaltoClub** es una app social para moteros con raids, rutas, clubs, economía gamificada y detección de caídas.

## Stack

| Capa | Tecnología |
|------|-----------|
| **App** | Flutter 3.12+ / Dart |
| **Auth** | Supabase Auth |
| **DB** | PostgreSQL + PostGIS (Supabase) |
| **Backend** | Dart Frog + Edge Functions |
| **Mapas** | Flutter Map + OpenRouteService + Offline (FMTC) |
| **Estado** | BLoC / flutter_bloc |

## Features

- 🗺️ **Mapa con rutas** — planeación, tracking GPS, offline tiles
- ⚔️ **Raids** — multiplayer en tiempo real con checkpoints y ranking
- 🏪 **Economía** — monedas, tienda, inventario, Battle Pass
- 🏅 **Showcase** — perfil tipo Steam con logros, patches y fotos
- 🛡️ **Safe Mode** — detección de caídas con acelerómetro + SOS automático
- 🏍️ **Clubs** — clanes con rangos, retos y códigos de acceso
- 🏪 **Refugios / Motoposadas** — puntos de encuentro para moteros
- 📏 **Mileage** — registro de kilómetros con verificación anti-fraude
